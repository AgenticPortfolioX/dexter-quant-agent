# API Keys Configuration

To use the Dexter Quant Agent, you need to obtain API keys from the following providers:

1.  **OpenAI**: [platform.openai.com](https://platform.openai.com/)
    *   Used for the primary reasoning model.
2.  **Financial Datasets**: [financialdatasets.ai](https://financialdatasets.ai/)
    *   Used for fundamental and historical stock market data.
3.  **Exa (formerly Metaphor)**: [exa.ai](https://exa.ai/)
    *   Used for advanced web searching and news gathering.
4.  **Tavily**: [tavily.com](https://tavily.com/)
    *   Alternative web search provider.

Once you have the keys, add them to the `.env` file located in the `dexter-core/` directory.
